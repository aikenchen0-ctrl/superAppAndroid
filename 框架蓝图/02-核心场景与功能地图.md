# 核心场景与功能地图

## 用户任务闭环

```text
发现待处理会话 -> 唤起悬浮工作台 -> 阅读上下文 -> AI 辅助生成 -> 用户编辑确认 -> 执行并记录 -> 复盘与配置
```

## 场景一：处理未读会话

1. 用户从侧边手势或快捷设置入口唤起工作台。
2. 顶部显示“全部未读”或当前账号未读状态，右侧切换已授权账号。
3. 用户选择会话，读取历史与新消息；加载、空数据和同步失败必须区分展示。
4. 用户阅读客户标签、地区、最近互动和消息上下文。
5. AI 输出草稿，用户可编辑、重试、放弃或确认发送。

## 场景二：发送素材与业务资料

1. 用户在输入栏通过“更多”选择相册、相机、文件、位置、名片或收藏。
2. 系统仅请求该动作所需权限，并提供预览。
3. 用户确认接收对象和内容后执行发送。
4. 系统将本次操作与会话、素材、发起人、时间和结果关联。

## 场景三：客户资料辅助

1. 用户从当前会话头像进入资料侧面板。
2. 展示姓名/备注、标签、共同群、关系记录和最近互动，数据源须标明同步时间。
3. AI 可针对可见资料生成建议，不得把敏感资料发送到未授权外部服务。
4. 第一阶段仅支持只读与建议；写回 SCRM 必须独立授权和二次确认。

## 场景四：临时暂停与恢复

1. 用户通过磁贴、通知或设置暂停边缘手势和覆盖层。
2. 暂停状态必须立即可见且可恢复。
3. 命中黑名单、横屏、键盘显示或系统手势冲突时，按配置自动禁用对应触控区域。

## 功能地图

| 域 | 已有基础 | 近期建设 | 远期探索 |
|---|---|---|---|
| 侧边控制 | 左右/底部手势、暂停、黑名单 | 可视化校准、冲突诊断 | 个性化手势推荐。 |
| 悬浮聊天 | 媒体、联系人、群聊、消息气泡、连线 | 顶部状态、输入快捷栏、消息同步验收 | 异形工具弹层。 |
| AI 助手 | 语音、眨眼、草稿原型 | 可编辑草稿、模板、确认审计 | 多 Agent 工作流。 |
| SCRM | 54 个接口与局部契约 | bootstrap/history/changes 真机验收 | 实时推送与跨平台聚合。 |
| 运营工具 | 朋友圈、素材、快捷语、收藏 | 客户资料只读、任务看板 | 合规审查后的工作流市场。 |

## 信息架构

- 主应用：服务状态、权限引导、侧边手势配置、账号与网络诊断。
- 悬浮工作台：顶部状态、会话左栏、消息中区、账号/工具右栏、输入底栏。
- 资料面板：联系人、群聊、素材、任务与审计记录。
- 管理设置：数据来源、AI 配置、风险策略、隐私和日志。
