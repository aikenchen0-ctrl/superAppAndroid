# 数据模型与权限边界

## 建模目标

以账号隔离、来源可追溯、权限最小化和本地可恢复为原则，支撑会话、客户资料、AI 草稿、工具执行和审计，而不把第三方平台的数据语义强行混为一谈。

## 核心实体

| 实体 | 关键字段 | 说明 |
|---|---|---|
| Account | id、平台、显示名、授权状态、组织 id | 所有业务数据必须归属账号。 |
| Conversation | id、accountId、远端 id、类型、未读、最后同步 | 单聊、群聊和系统会话统一入口。 |
| Message | id、conversationId、作者、类型、内容引用、远端时间、同步状态 | 原文与展示模型分离。 |
| Contact | id、账号范围、名称、标签、资料版本、数据来源 | 客户资料必须标示来源和同步时间。 |
| MediaAsset | id、uri、MIME、大小、来源、权限状态 | 不在日志保存原始敏感媒体。 |
| AiDraft | id、上下文引用、版本、内容、模型配置、确认状态 | AI 输出可编辑、可对比、可撤销。 |
| ExecutionRecord | id、动作、目标、发起人、确认人、结果、错误 | 所有外部写操作必须可审计。 |

## 账号与租户隔离

- 数据查询必须带 `organizationId` 和 `accountId` 过滤条件。
- UI 切换账号时，清空不属于目标账号的会话和缓存引用。
- 本地数据库迁移以版本化方式进行，迁移失败不能静默清库。
- 跨账号聚合只能展示用户具备权限的摘要，进入详情时再次校验。

## 权限模型

| 权限 | 用途 | 原则 |
|---|---|---|
| 无障碍 | 系统辅助与覆盖层联动 | 用户在系统设置显式授予，可随时关闭。 |
| 悬浮窗 | 展示工作台 | 仅在功能启用时使用。 |
| 相机/麦克风 | 拍摄、语音、眨眼试验 | 用时申请，常驻状态可见。 |
| 媒体/文件 | 用户主动选择附件 | 使用系统选择器，最小范围访问。 |
| 网络 | SCRM/AI 服务 | HTTPS、超时、证书与错误可观测。 |

## 数据保留与删除

草稿、缓存、日志和媒体必须有独立保留策略。退出账号、撤销授权或用户请求删除时，先标记范围、提示影响、执行可验证的清理，并记录清理结果。不得在源代码或示例配置中存放接口账号、密码、Token 等凭据。
