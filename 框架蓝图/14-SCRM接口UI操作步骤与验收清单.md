# SCRM 接口 UI 操作步骤与验收清单

## 1. 配置与连接

1. 打开 App 主界面的 SCRM 设置。
2. 填写服务地址和 API Key，点击保存配置。
3. 点击测试连接，确认能力状态返回成功。
4. 读取设备列表和微信账号列表，选择实际路由并保存。
5. 打开悬浮聊天，确认会话摘要、头像、未读数和最近消息来自 SCRM。

## 2. 聊天读取与发送

1. 选择一个会话，上滑触发历史分页，确认消息按时间顺序追加。
2. 返回会话列表后再次进入，确认摘要和未读状态来自 SCRM。
3. 输入文本点击发送，观察“发送中”变为成功或失败。
4. 对图片、视频、语音、文件分别重复发送并检查任务终态。

## 3. 联系人和好友申请

1. 打开联系人面板，确认列表使用当前选中的微信账号。
2. 点击联系人进入资料页，查看详情、客户画像和标签。
3. 使用查找好友、手机号加好友或场景加好友，二次确认后执行。
4. 打开好友申请，处理一条申请并等待任务终态。
5. 在资料页执行删除好友，确认结果和失败原因可见。

## 4. 群聊操作

1. 进入群详情页并打开成员选择。
2. 邀请成员、移出成员、修改群名称、发布群公告、拉取群二维码、退出群聊各执行一次。
3. 每次操作确认后提交，并等待任务终态。
4. 对免打扰、置顶、保存通讯录等入口，确认其当前只改变本地悬浮窗口状态，不误报为服务端成功。

## 5. 朋友圈与素材

1. 打开朋友圈面板并执行同步。
2. 查看互动消息，分别执行点赞和评论。
3. 发布一条朋友圈，确认发送结果。
4. 在素材列表查看详情，执行创建、复制和归档。

## 6. 当前不可作为真实接口验收的入口

消息转发、撤回、语音转文字、媒体下载、原文补拉、收藏表情、小程序卡片、批量发送、客户画像保存、批量标签和高级群管理目前只展示请求预览或本地状态。验收记录应写为“UI 已有入口/请求未发送”。
