## 4. 已接入 UI 的真实链路

会话启动由 `ScrmSettingsManager` 读取配置并选择设备/微信账号，`ScrmFloatingChatBridge` 依次调用设备、账号、能力、`chat/bootstrap`、`chat/history` 和 `messages/changes`，再映射为悬浮聊天模型。普通消息先进入本地 outbox，再由 `ScrmOutboxDispatcher` 调用发送接口；服务返回 `taskId` 后由 `ScrmTaskTracker` 轮询终态。

联系人列表、详情、客户画像读取、同步、查找好友、好友验证/添加/删除、好友申请处理和创建群聊已进入真实客户端调用。群详情页中邀请成员、移出成员、改群名、群二维码、群公告和退出群聊通过 `ScrmContactTaskRunner.submitAndAwait` 执行。朋友圈同步、互动消息同步、发布、点赞、评论，以及素材列表、详情、创建、复制、归档已由 moments UI 调用。

## 5. 仅预览或本地状态

消息转发、撤回、语音转文字、详情补拉、媒体下载、原文补拉、表情详情、收藏表情发送、小程序卡片和筛选批量发送目前只组装请求并展示预览，不发送请求。客户画像保存、批量标签，以及群免打扰、置顶、保存通讯录、群内昵称、聊天背景等也分别是预览或悬浮窗口本地状态。
