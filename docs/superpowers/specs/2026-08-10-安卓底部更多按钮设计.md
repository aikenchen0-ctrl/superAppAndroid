# Android 底部 More 按钮设计

## 目标

在悬浮聊天底部输入栏增加独立的 `MoreInputButton`，位置与 iOS `InputBarView.moreButton` 对齐，并打开 Android 已有的 `BottomPanelMode.More` / `MoreToolPanel`。

## 范围

- 新增独立 Compose 按钮组件，负责图标、激活态和无障碍描述。
- 将按钮接入 `BottomInputBar`，顺序为 `Home, Voice, Text, Gift, More, Assistant`。
- 点击在 `More` 与 `None` 之间切换。
- 不新增工具项，不接入新的后端接口，不实现输入框上方快捷按钮组。

## 验收

1. 单元测试验证 `More` 出现在 Gift 后、Assistant 前。
2. 单元测试验证 More 面板切换状态的纯逻辑。
3. 真机验证按钮可见、点击打开已有 More 面板、再次点击可关闭，面板内容无回归。
