# 安卓账号设备轨道还原设计

## 目标

参考 `ios-float` 的“帐号设备”右侧轨道，将安卓悬浮聊天中的账号头像轨道按同等比例还原，同时保留现有账号数据、点击切换、长按编辑、连接器坐标和独立滚动行为。

## 设计

- 账号头像单元统一为 `50dp`，对应 iOS 参照实现的约 `50pt`。
- 工具按钮宽度为 `50dp`、高度为 `44dp`，与 iOS 的工具单元比例一致。
- 账号区默认占右侧轨道可用高度的 `48%`，工具区占 `52%`。
- 账号区和工具区之间保留紧凑分隔区域，避免浪费窄轨道空间。
- 账号头像继续使用远程头像、本地头像和首字母回退；选中账号使用强调色描边和阴影，在线状态保留状态点。

## 范围

只调整右侧账号设备轨道及其尺寸契约，不改 SCRM API、账号选择接口和消息数据映射。

## 验证

通过安卓生产 Kotlin 编译、右侧轨道契约测试，并安装 Debug APK 到连接设备进行人工确认。工作区已有的其他测试错误不归属于本次改动。
