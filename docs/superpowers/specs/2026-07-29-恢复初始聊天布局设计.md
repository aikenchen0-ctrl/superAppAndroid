# 恢复初始聊天布局设计

## 目标

以提交 `0ff8e40` 的聊天界面为视觉和布局基线，恢复项目最开始的聊天结构，同时保留已经完成的“未回消息”数据、入口和状态行为。

用户在手机上看到的普通聊天与未回消息聚合页都使用同一套初始聊天布局。聊天头部、联系人列表和消息列表处于同一个常规内容层级，不再通过未回消息专用悬浮层、坐标面板或连接层改变原始界面结构。

## 保留范围

- 左上角“未回消息”按钮。
- 全账号未回消息聚合数据，以及账号筛选能力。
- 群聊未回消息优先级：优先展示包含 `@账号名`、账号名、“待回复”或“待确认”的消息；没有优先消息时展示最新 3 条。
- 未回总数保持全部有效未回消息数量，不受展示条数影响。
- 从普通会话通过底部 Home 进入全账号未回消息聚合页。
- 从聚合页进入会话后，点击“未回消息”按钮返回上一个最新状态的聚合页。
- 返回时保留聚合页的账号筛选、列表位置和会话位置。
- Home、返回和“未回消息”按钮均不得清除未回记录。
- Debug 群聊测试数据继续保留，Release 不注入测试数据。

## 恢复范围

- 聊天头部恢复为 `0ff8e40` 的结构、尺寸、间距和层级。
- 联系人列表恢复为初始实现，不使用未回消息专用联系人坐标布局。
- 消息列表恢复为初始消息容器和消息行布局。
- 右侧账号栏恢复初始结构和交互区域。
- 底部输入栏完整恢复并保持初始实现，不增加未回消息专用控件。
- 普通聊天和未回消息聚合页共享初始聊天布局骨架。

## 删除或停用的界面能力

- 未回消息专用聚合头部。
- 头像到气泡、气泡到账号栏的连接线及其坐标采集层。
- 未回消息专用消息坐标面板。
- 为聚合页新增的悬浮、吸附或独立 zIndex 层。
- 改变初始消息气泡、消息行、账号栏视觉的未回消息专用样式。

未使用的专用 UI 文件和相关死代码应删除；数据模型、聚合推导和导航状态代码继续保留。

## 布局结构

界面继续采用初始聊天布局的固定区域关系：

1. 聊天头部位于内容顶部。
2. 联系人列表和消息列表沿用初始结构排列。
3. 右侧账号栏沿用初始位置。
4. 底部输入栏沿用初始位置和尺寸。

这些区域由同一个聊天内容容器管理。未回消息模式只改变数据源和左上角入口状态，不创建新的覆盖层，也不改变普通聊天的测量、绘制和触摸顺序。

## 交互行为

### 进入聚合页

- 普通会话点击底部 Home，切换到全账号未回消息聚合页。
- 聚合页使用初始聊天布局展示联系人和对应未回消息。
- 全账号聚合页不显示左上角“未回消息”按钮。

### 进入会话

- 从聚合页点击联系人或群聊，进入对应会话。
- 会话左上角显示“未回消息”按钮。
- 底部输入栏行为与初始聊天完全一致。

### 返回聚合页

- 点击“未回消息”按钮返回最近一次聚合页状态。
- 恢复账号筛选、列表滚动位置和当前浏览位置。
- 返回动作只切换导航状态，不修改未回消息集合。

## 数据边界

- 未回消息推导、分组、群聊优先级和未回数量属于业务层，不随 UI 恢复而回退。
- UI 只消费现有未回消息摘要和导航状态，不重新维护一份消息集合。
- 普通消息持久化、SCRM 数据和 Debug fixture 的来源保持不变。
- 不增加静默 fallback 或假成功路径；数据加载失败继续明确暴露。

## 实施边界

优先以 `0ff8e40` 对应文件为基线逐文件恢复视觉结构，再最小接回未回消息入口和状态参数。不得整体回退分支，也不得覆盖用户现有未跟踪文件或手机数据库。

重点审查以下文件：

- `FloatingChatOverlayUi.kt`
- `CoordinateChatBody.kt`
- `MessageCoordinatePane.kt`
- `ChatConnectorLayer.kt`
- `MessageListPresentation.kt`
- `MessageRow.kt`
- `RightCoordinateRail.kt`
- `UnrepliedOverviewHeader.kt`
- `UnrepliedDraftUi.kt`

业务状态集中在 `ChatThreadState.kt`、`UnrepliedOverviewState.kt` 和导航状态代码中，除适配初始布局所需的接口调整外不回退行为。

## 验证标准

### 自动化验证

- 添加或调整契约测试，证明未回消息模式不再依赖专用头部、连接层和消息坐标面板。
- 保留未回消息聚合、群聊优先级、Home 导航、返回状态和不清除记录的测试。
- 运行 `:ubiki-accessibility:testDebugUnitTest`。
- 运行 `:app:assembleDebug`。

### 真机验证

- 普通聊天与未回消息聚合页视觉结构和 `0ff8e40` 基线一致。
- 聊天头部、联系人列表、消息列表不存在互相覆盖。
- 全账号聚合页无“未回消息”按钮；具体会话左上角有该按钮。
- Home 能进入全账号聚合页。
- 点击“未回消息”按钮能恢复聚合页原位置和筛选状态。
- 上述导航均不清除未回记录。
- 右侧账号切换无明显卡顿。
- 底部输入栏与初始版本一致。

## 风险控制

- 恢复 UI 文件时可能误删未回消息入口参数，必须通过编译和导航测试约束。
- 初始布局与当前拆分后的文件边界不同，应恢复组件行为而不是机械覆盖整个目录。
- 移除坐标层后必须同时删除无效测量和重组触发，避免保留性能负担。
- 手机现有测试数据库和设备截图不属于源码改动，不提交、不删除。
