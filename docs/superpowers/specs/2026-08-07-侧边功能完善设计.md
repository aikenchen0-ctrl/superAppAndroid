# 侧边功能完善设计

## 目标

为无障碍边缘悬浮手势提供可配置的快捷功能面板，替代现有“功能一/功能二”演示项；同时扩大边缘指示器并统一上下滑的反馈与误触阈值。

## 范围

### 主界面入口

主界面新增“侧边功能”卡片，说明其用于配置边缘手势被触发后显示的快捷功能。点击该卡片进入独立的 `SideFunctionsActivity`。

### 配置模型

侧边功能是一份全局配置，存储在 `UbikiPreferences`：

- 固定功能：`关闭所有`、`返回`，永远位于前两项，不可删除、不可排序。
- 自定义功能：最多五项，按保存顺序显示和执行。
- 自定义功能可选择既有 `GestureActionCatalog` 中的动作，以及 `LaunchApp(packageName)`。
- 配置变化后，无障碍服务的下一次手势读取最新配置，不复制动作执行逻辑。

### 配置页面交互

页面展示固定区和自定义区。添加按钮在自定义项少于五个时可用，点击后打开动作选择器。

选择“打开 App”后显示应用选择页或对话框，包含“用户安装”和“系统应用”两个 Tab，默认“用户安装”。应用按 `ApplicationInfo.FLAG_SYSTEM` 分类，并显示应用名和包名。

长按任一自定义项进入编辑状态：

- 自定义项可通过拖动重新排序。
- 页面底部显示删除区域；拖入后删除该功能。
- 点击完成或退出编辑状态后立即保存新顺序。
- 固定项不会进入拖动或删除流程。

### 浮窗功能面板

横向拉出边缘手势后，浮窗按固定项优先、自定义项随后显示功能名称。布局按功能数量均分可点击高度并保留间距；手指进入某项命中区域即执行其动作并收起面板。

固定动作的定义：

- `关闭所有`：关闭本应用创建的悬浮聊天、视频、手势特效与临时功能面板；边缘手势覆盖层及无障碍服务继续运行。
- `返回`：调用无障碍全局返回动作。

其他动作继续委托 `UbikiActionExecutor`，包括启动已安装应用。

### 指示器与上下滑反馈

- 边缘手势指示器尺寸增大，仍由独立、不可触摸的窗口绘制并固定在物理屏幕边缘。
- 上滑与下滑均绘制同一视觉语言的方向线条，方向随手势变化。
- 提高上下滑的最小识别距离；只有超过阈值才提交动作，以减少轻微移动造成的误触。

## 架构

```text
MainActivity 卡片 -> SideFunctionsActivity -> UbikiPreferences
                                             |
边缘手势 -> UbikiAccessibilityService -> BackWaveOverlayController
                                             |
                                  UbikiActionExecutor / 临时浮窗清理
```

- `ubiki-core`：定义可序列化的侧边功能条目、顺序和面板命中布局，提供单元测试目标。
- `app`：负责设置入口、配置 Activity、动作选择与应用分类 UI。
- `ubiki-accessibility`：读取配置，渲染名称、命中并执行动作，负责“关闭所有”的临时浮窗清理。
- `ubiki-overlay`：调整指示器尺寸与上下滑阈值/方向反馈，不承担配置持久化。

## 错误处理

- 已选择应用被卸载时，启动动作显示现有失败提示，不移除该配置。
- 配置项解析失败时忽略无效项，不影响固定动作与服务运行。
- 达到五项上限时禁用添加入口，不静默丢弃已有项。

## 验证

- 单元测试：序列化、上限、排序、固定项顺序、应用分类、功能面板命中、上下滑阈值及方向线条。
- 编译：`:app:compileDebugKotlin` 与相关模块单测。
- 构建：`:app:assembleDebug`。
