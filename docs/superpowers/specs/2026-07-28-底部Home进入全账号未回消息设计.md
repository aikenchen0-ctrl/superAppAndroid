# 底部 Home 进入全账号未回消息设计

## 目标

点击底部输入栏的 Home 键时，始终切换到全账号未回消息聚合页，不保留上一次单账号筛选。

同时消除未回消息聚合页点击右侧账号筛选时的额外连接线重绘和列表位置校正，降低点击卡顿。

## 状态转换

- 使用最新账号和未回事项恢复聚合页状态。
- 将 `visible` 设为 `true`。
- 将 `accountFilterId` 清空，确保展示全账号事项。
- 保留有效的选中事项、滚动位置、草稿模式、草稿内容、头像水印和账号色点配置。
- 关闭当前底部面板。

## 行为边界

- 只修改底部 Home 键的点击语义。
- 左上角“未回消息”入口继续恢复上一次聚合页状态，包括有效的单账号筛选。
- 单账号聚合页左上角返回操作继续只清空账号筛选。
- 输入框聚焦时 Home 键替换为表情按钮的规则保持不变。
- 不修改连接线、消息推导、草稿发送和底部输入框布局。

## 账号筛选性能

### 根因

- 右侧账号头像点击时会更新“选中账号头像”坐标并使连接层失效；聚合页的账号连接只读取普通账号头像坐标，因此该更新没有业务作用。
- 账号筛选改变后状态中的滚动位置被设为零，但实际 `LazyListState` 的视口键不包含账号筛选，列表可能保留旧位置，再由布局和状态监听进行额外校正。

### 修正

- 聚合页点击右侧账号头像时不更新“选中账号头像”坐标；普通聊天切换账号时保持原行为。
- 将 `accountFilterId` 纳入聚合列表视口标识。
- 筛选改变时只请求一次滚动到首项，并同步保存的首项索引和偏移。
- 不隐藏连接线，不增加延迟、加载假状态或静默降级。

## 测试

- 保存状态含单账号筛选时，底部 Home 转换结果的 `accountFilterId` 为 `null`。
- 最新事项为空时仍进入可见的全账号空状态，并重置无效滚动位置。
- 草稿、显示配置和有效选中事项保持不变。
- 原有 `restoreUnrepliedOverviewState` 继续保留有效单账号筛选，证明左上角入口语义未改变。
- 聚合页账号点击不触发选中账号坐标更新，普通聊天仍触发。
- 相同会话下切换不同账号筛选会产生不同视口键。
- 筛选后列表首项索引和偏移稳定为零，不发生状态来回覆盖。

## 验收标准

1. 从普通聊天或单账号未回消息页点击底部 Home，进入全账号未回消息聚合页。
2. 页面使用当前最新未回事项，不显示已失效筛选或事项。
3. 左上角“未回消息”入口仍能恢复上一次有效聚合状态。
4. 底部输入栏布局和聚焦后表情按钮行为不变。
5. 点击右侧账号筛选时不再执行无用的选中账号连接坐标更新。
6. 账号筛选后列表直接定位首项，无旧滚动位置跳动或二次校正。
