# 未回消息手机端设计

## 目标

在现有 Android 悬浮聊天界面中补齐“未回消息”功能，使用户能够从普通聊天界面进入跨账号待回复事项聚合页，查看连续未回复消息、筛选账号、使用 AI 草稿回复，并在离开后恢复上一次聚合页的最新状态。

## 范围

- 普通聊天界面左上角增加“未回消息”按钮。
- 全账号未回消息聚合页不显示“未回消息”按钮。
- 支持全部账号与单账号的未回事项聚合展示。
- 支持连续未回消息分组、账号归属标识、AI 草稿展示与回复闭环。
- 从聚合页进入会话后，再点击“未回消息”按钮时恢复上一次聚合页状态。
- 未回事项数据始终根据当前会话数据重新计算。

## 明确不做

- 不修改底部输入栏的结构、按钮或聚焦行为。
- 不绘制发送者、消息、收件账号之间的连接线。
- 不提供连接线开关或连接线样式配置。
- 不新增后端接口、假成功返回、静默降级或独立的平行消息数据源。

## 入口与导航

### 普通聊天界面

左上角显示“未回消息”按钮。点击后：

1. 如果存在有效的聚合页历史状态，则恢复该状态。
2. 如果是首次进入或历史状态不可恢复，则进入全账号聚合页。
3. 进入前重新从当前账号会话数据推导未回事项。

### 全账号聚合页

- 左上角显示“全部账号 · N 项”，不显示“未回消息”按钮。
- 右侧账号头像继续承担单账号筛选入口。
- 点击一个未回消息组，切换到事项所属账号并打开对应会话。

### 单账号聚合页

- 标题显示账号名称与事项数量。
- 左上角显示“< 未回消息”，点击后返回全账号聚合状态。
- 返回全账号聚合状态时保留可继续使用的聚合页状态。

## 未回消息判定

以“账号 + 会话”为隔离边界：

1. 获取该账号在该会话内最后一次有效自发回复的位置。
2. 只检查该位置之后的消息。
3. 保留来自对方、可展示且内容有效的消息。
4. 排除 AI 草稿、系统提示和当前账号自己发送的消息。
5. 当账号发送有效回复后，重新计算该会话；已经被回复的事项从聚合页消失。

群聊和私聊均沿用现有会话选择、账号归属和消息可见性规则，不在 UI 层重复业务判定。

## 展示结构

### 消息分组

- 同一账号、同一会话中连续待回复的消息组成一个消息组。
- 消息组只展示一次左侧发送者头像。
- 组内消息保持原始时间顺序。
- 不绘制头像到气泡或气泡到账号栏的连接线。

### 账号归属标识

- 每条气泡可显示收件账号头像水印。
- 每条气泡可显示收件账号颜色点。
- 顶部配置入口只控制头像水印和账号颜色点，不包含连接线选项。
- 配置状态属于聚合页恢复状态的一部分。

### 空状态

没有待回复事项时显示明确的“所有消息均已回复”空状态。空状态不注入演示消息，不伪造成功结果。

## AI 草稿

聚合页提供两种展示方式：

- 列表草稿：草稿随当前未回消息组展示。
- 底部草稿：草稿展示在现有内容区域的底部草稿区域，不修改现有底部输入栏。

草稿按账号和会话隔离保存。发送草稿时复用现有消息发送路径；发送成功后重新推导未回事项。若发送失败，明确保留错误状态和草稿内容，不移除事项。

## 状态恢复

离开聚合页时保存以下 UI 状态：

- 全账号或单账号筛选状态。
- 列表滚动位置。
- 当前选中的未回事项。
- 列表草稿或底部草稿模式。
- 尚未发送的会话草稿。
- 收件账号头像水印与颜色点配置。

再次点击普通聊天界面左上角“未回消息”按钮时：

1. 先用最新会话数据重新计算未回事项。
2. 恢复仍然有效的筛选、滚动、草稿和配置状态。
3. 如果原选中事项仍存在，则恢复选中。
4. 如果原选中事项已经消失，则取消选中，不自动选择其他事项。
5. 如果原账号筛选已不存在，则回到全账号聚合页。
6. 滚动位置超出新列表范围时，收敛到最近的有效位置。

状态仅保存在当前悬浮聊天运行会话中，不新增跨进程持久化。

## 组件边界

- `ChatThreadState`：负责未回事项推导、账号隔离、消息分组和稳定标识。
- 聚合页状态对象：负责筛选、滚动、选中事项、草稿模式和展示配置。
- `CoordinateChatBody` / `MessageCoordinatePane`：负责聚合页布局和消息组展示。
- 顶部栏：负责入口按钮、状态标题、草稿模式与收件账号标识配置。
- 现有消息发送路径：负责发送草稿并将结果写回会话数据。

不在 Composable 内复制未回消息业务判断，也不创建第二套会话仓库。

## 错误处理

- 会话或账号无法解析时，该事项不进入可交互聚合结果，并通过现有日志机制暴露原因。
- 草稿发送失败时保留草稿与事项，显示明确失败状态。
- 状态恢复引用失效事项时仅清除失效引用，不吞掉数据推导或发送错误。

## 测试策略

按测试优先顺序覆盖：

1. 普通聊天页显示入口，全账号聚合页隐藏入口。
2. 首次进入打开全账号聚合页。
3. 再次进入恢复上一次有效状态，同时使用最新未回数据。
4. 最后一次有效回复之后的对方消息才进入聚合结果。
5. 同一会话连续消息正确分组且只显示一个发送者头像。
6. 全账号与单账号筛选及返回行为正确。
7. 头像水印和账号颜色点配置生效且可恢复。
8. 两种草稿模式不修改底部输入栏。
9. 草稿发送成功后事项消失，失败后事项和草稿保留。
10. 空状态、失效选中项和越界滚动位置能够明确处理。

## 验收标准

- 用户可以从普通聊天界面左上角进入未回消息聚合页。
- 全账号聚合页不出现“未回消息”入口按钮。
- 页面能够正确展示跨账号连续未回消息及账号归属。
- 用户可以筛选账号、打开会话、返回并恢复上一次聚合页最新状态。
- 用户可以切换草稿展示方式并完成真实回复闭环。
- 底部输入栏没有结构或行为变化。
- 页面没有任何连接线或连接线配置。
- 相关单元测试、模块测试和 Android 构建验证通过。
