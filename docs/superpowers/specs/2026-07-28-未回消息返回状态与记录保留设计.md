# 未回消息返回状态与记录保留设计

## 目标

从未回消息聚合页进入会话后，再点击左上角“未回消息”按钮时，返回上一次聚合页的最新有效状态和相同列表位置。查看事项不能直接清除未回消息记录。

## 查看事项

- 点击未回消息气泡只切换到事项所属账号和会话。
- 保存当前账号筛选、选中事项、列表首项索引和像素偏移。
- 不从未回或未读标识集合中移除该会话。
- 不修改消息数据，不生成已回复状态，不删除聚合事项。
- 只有真实回复消息进入现有消息数据后，事项才按“最后一次有效回复后的连续未回消息”规则重新计算并消失。

## 返回聚合页

- 左上角“未回消息”入口继续调用 `restoreUnrepliedOverviewState`。
- 使用当前最新账号和事项校验保存的筛选与选中事项。
- 有效账号筛选继续保留。
- 有效选中事项继续保留；事项已因真实回复消失时清除选中状态。
- 列表恢复保存的首项索引与精确像素偏移。
- 如果最新事项数量减少，索引只做必要的范围收敛。

## 视口切换规则

- 普通会话切回未回消息聚合页：恢复保存位置。
- 未回消息聚合页切换右侧账号筛选：定位新筛选结果首项，偏移为零。
- 未回消息聚合页进入普通会话：普通会话继续定位自己的消息位置。
- 底部 Home：进入全账号聚合页，并按其既有规则定位全账号视图。

## 测试

- `openHomeUnread` 不移除未回会话 ID。
- 普通会话切回聚合页时，视口目标为保存的索引和偏移。
- 聚合页账号筛选变化时，视口目标为 `0, 0`。
- 最新事项减少时恢复索引不会越界。
- 左上角入口保留有效筛选、草稿、显示配置和滚动位置。

## 验收标准

1. 点击未回事项进入会话后，该事项仍保留，除非用户实际发送了回复。
2. 再点击左上角“未回消息”时返回之前的账号筛选和列表位置。
3. 返回后展示基于最新消息重新计算的聚合内容。
4. 账号筛选切换仍从新结果顶部开始，不错误恢复其他筛选的位置。
