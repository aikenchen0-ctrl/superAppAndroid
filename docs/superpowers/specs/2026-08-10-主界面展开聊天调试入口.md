# 主界面展开聊天调试入口

## 目标

在 Android 主界面最上方提供一个仅用于 Debug 构建的“展开聊天”按钮，使测试人员无需手势操作即可展开真实悬浮聊天窗口。

## 范围

- `MainActivity` 的主页顶栏展示 Debug 调试入口。
- 点击入口必须调用无障碍服务内现有 `FloatingChatOverlayController.expand()`，不新增第二套悬浮窗。
- 无障碍服务未连接或悬浮层控制器未初始化时，入口不可点击并明确显示未就绪状态。
- Release 构建不展示该入口。

## 非范围

- 不调整悬浮聊天布局、手势配置或聊天业务接口。
- 不修改微信头像接口实现；该工作作为独立任务卡排入测试与开发计划。

## 设计

无障碍服务新增一个公开的调试展开请求方法。该方法在服务主线程检查 `floatingChatOverlayController` 是否已初始化，初始化后调用其 `expand()`；未初始化时返回失败结果，供 UI 显示真实状态。

`HomeDashboardScreen` 接收展开回调和可用状态。顶栏在 `BuildConfig.DEBUG` 时显示“展开聊天”按钮，按钮位于现有标题之上；服务未就绪时禁用。点击成功后由现有控制器刷新会话并展示 Expanded 悬浮窗。

## 验收

1. Debug APK 主界面顶部可见“展开聊天”。
2. 开启无障碍服务后，点击按钮可直接展开现有悬浮聊天窗口。
3. 服务未启动时按钮不能触发展开，且状态表达为未就绪。
4. Release 变体不包含该按钮。
5. 单元测试覆盖服务未初始化与已初始化两种分支；Debug APK 可成功构建。
