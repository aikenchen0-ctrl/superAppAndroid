# 无障碍保活 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add ROOT/ADB accessibility keep-alive with a switch and copyable guide.

**Architecture:** Keep platform-independent command/list logic in `:app`; use `:ubiki-accessibility` for the service component and preference; merge AdbKeeper as `:adbcore`, initialized from the application. UI is Compose and all shell work runs off the main thread.

**Tech Stack:** Kotlin, Android Compose Material 3, coroutines, AdbKeeper native ADB core, JUnit.
