# 未回消息手机端实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Android 悬浮聊天界面补齐左上角未回消息入口、跨账号聚合展示、最新状态恢复、账号归属标识和两种 AI 草稿展示模式，同时保持底部输入栏不变并移除聚合页连接线。

**Architecture:** 继续使用 `ChatThreadState.kt` 从真实会话推导未回事项；新增不可变的聚合页状态模型，集中处理账号筛选、选中项、滚动锚点、草稿模式和标识配置。`FloatingChatOverlayUi.kt` 负责保存运行期状态并编排现有发送动作，专用 Compose 组件负责顶部控制和聚合草稿展示，`CoordinateChatBody.kt` 在聚合模式下不再创建连接线层。

**Tech Stack:** Kotlin 2、Jetpack Compose、Android Gradle Plugin、JUnit 4、现有 `ubiki-accessibility` 测试契约。

```kotlin
internal enum class UnrepliedDraftMode { Inline, Bottom }

internal data class UnrepliedDraftKey(val accountId: String, val threadId: String)

internal data class UnrepliedRecipientIndicators(
    val watermarkVisible: Boolean = true,
    val colorDotVisible: Boolean = true
)

internal data class UnrepliedOverviewState(
    val visible: Boolean = false,
    val accountFilterId: String? = null,
    val selectedItemId: String? = null,
    val firstVisibleItemIndex: Int = 0,
    val firstVisibleItemScrollOffset: Int = 0,
    val draftMode: UnrepliedDraftMode = UnrepliedDraftMode.Bottom,
    val drafts: Map<UnrepliedDraftKey, String> = emptyMap(),
    val indicators: UnrepliedRecipientIndicators = UnrepliedRecipientIndicators()
)

internal fun restoreUnrepliedOverviewState(
    saved: UnrepliedOverviewState,
    availableAccountIds: Set<String>,
    availableItemIds: List<String>
): UnrepliedOverviewState {
    val accountFilter = saved.accountFilterId?.takeIf(availableAccountIds::contains)
    val selectedItem = saved.selectedItemId?.takeIf(availableItemIds::contains)
    val maxIndex = availableItemIds.lastIndex.coerceAtLeast(0)
    return saved.copy(
        visible = true,
        accountFilterId = accountFilter,
        selectedItemId = selectedItem,
        firstVisibleItemIndex = saved.firstVisibleItemIndex.coerceIn(0, maxIndex)
    )
}
```
