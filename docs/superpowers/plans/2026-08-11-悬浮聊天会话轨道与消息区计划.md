# 悬浮聊天会话轨道与消息区 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完善悬浮聊天左侧会话轨道的选中态操作和消息区气泡/多选行为。

**Architecture:** 将可测试的停留计时与会话摘要规则放在 `ChatLayoutState.kt`，把 Compose 布局与父级回调放在 `ChatSessionRail.kt`。消息区只复用既有 message renderer 与交互状态，避免把 SCRM 请求放入 Composable。

**Tech Stack:** Kotlin、Jetpack Compose、Compose LazyColumn、JVM 单元测试。
