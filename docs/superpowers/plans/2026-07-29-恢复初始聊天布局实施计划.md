# 恢复初始聊天布局实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 恢复 `0ff8e40` 的初始聊天布局，只保留未回消息数据、左上角按钮和既有导航状态行为。

**Architecture:** 业务状态继续由 `ChatThreadState` 与 `UnrepliedOverviewState` 维护，界面重新使用初始聊天骨架。未回消息模式仅替换联系人和消息数据，并通过初始头部的 leading action 暴露入口，不再建立专用 Header、坐标面板或连接层。

**Tech Stack:** Kotlin、Jetpack Compose、JUnit、Gradle Android、ADB。
