# 客户画像、标签与朋友圈权限 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在联系人详情页完成单联系人客户画像、联系人标签和朋友圈权限的确认式保存、任务终态等待与保存后回读。

**Architecture:** Composable 只负责快照展示、编辑草稿和 UI intent；`ScrmContactsPanel` 负责账号路由、IO 调度和 API 调用。画像使用 PUT 后 GET 回读，标签和朋友圈权限使用现有 `ScrmContactTaskRunner` 等待任务终态后 GET 详情回读。批量接口不进入本期联系人详情。

**Tech Stack:** Kotlin、Jetpack Compose Material 3、kotlinx.serialization、现有 `ScrmApiClient`、`ScrmContactTaskRunner`、JUnit。
