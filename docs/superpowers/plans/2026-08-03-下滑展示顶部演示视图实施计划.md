# 下滑展示顶部演示视图 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在手势动作列表中新增“播放视频”，触发后通过无障碍 Overlay 从屏幕顶部向下展示一个可关闭的演示视图。

**Architecture:** 在 `ubiki-core` 增加稳定可持久化的动作 ID；在 `ubiki-accessibility` 新建独立 `VideoDemoOverlayController`，负责 Overlay 的创建、展开动画、切换关闭和销毁；`UbikiActionExecutor` 仅负责把动作转发给控制器。首版不接入视频源，不复用悬浮聊天媒体预览，避免两个生命周期互相影响。

**Tech Stack:** Kotlin、Android AccessibilityService、WindowManager、原生 View 动画、JUnit 4、Robolectric。
