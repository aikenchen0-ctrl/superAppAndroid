# 短视频流演示实现计划

> **For agentic workers:** 本计划在当前会话内执行，按 TDD 先写失败测试，再实现生产代码。

**目标：** 将现有右侧下滑触发的简单视频占位 Overlay 升级为可上下翻页的本地短视频 Demo，并加入流星手势反馈和抖音式操作栏。

**架构：** 保留 `GestureAction.PlayVideo` 与 `VideoDemoOverlayController` 的服务入口。新增纯 Kotlin 的 Demo feed 状态/数据和手势进度计算，Overlay 使用 `TYPE_ACCESSIBILITY_OVERLAY` 承载一个全屏原生 View，视频内容采用不依赖网络的 Canvas 动画演示，避免引入体积和兼容性不可控的外部媒体资源；交互、生命周期和错误状态由控制器统一管理。

**技术栈：** Kotlin、Android `WindowManager`、自定义 `View`/`Canvas`、现有无障碍服务与 JUnit。

- Canvas 生成三条循环 Demo 画面，当前页动画，切页后停止上一页动画。

- 流星效果使用有限时长的 Canvas 粒子和尾迹，动画结束自动清理，不遮挡后续页面交互。

文件：

- 修改 `ubiki-overlay/src/main/kotlin/com/paifa/ubikitouch/overlay/EdgeGestureDetector.kt`
- 修改 `ubiki-overlay/src/main/kotlin/com/paifa/ubikitouch/overlay/EdgeOverlayView.kt`

- 修改 `ubiki-accessibility/src/main/kotlin/com/paifa/ubikitouch/accessibility/NativeEdgeGestureController.kt`

行为：

- 为右侧向下滑动提供可选预览进度回调，保留现有构造函数默认行为。
- 服务只为右侧 `SWIPE_DOWN` 预览触发流星效果，取消手势时清理。
- 手势抬起后仍通过现有 `preferences.actionFor(side, type)` 执行 `PlayVideo`，不覆盖用户配置。
- `onDestroy`、服务重连、Overlay 关闭和系统返回都释放 View、动画和播放器/绘制任务。
