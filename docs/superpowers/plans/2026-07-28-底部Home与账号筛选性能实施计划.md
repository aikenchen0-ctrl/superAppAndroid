# 底部 Home 与账号筛选性能实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让底部 Home 始终进入全账号未回消息聚合页，并移除聚合页账号筛选时的无用连接坐标更新与列表二次位置校正。

**Architecture:** 将底部 Home 导航定义为纯状态转换；为消息列表视口键加入账号筛选维度；右侧账号栏显式接收是否应在点击时更新选中账号坐标。Compose 回调只组合这些可测试策略，不增加延迟或隐藏连接线。

**Tech Stack:** Kotlin、Jetpack Compose、JUnit 4、Gradle、ADB gfxinfo

- [ ] **Step 3: 实现纯状态转换**

```kotlin
internal fun openAllAccountsUnrepliedOverview(
    saved: UnrepliedOverviewState,
    availableAccountIds: Set<String>,
    availableItemIds: List<String>
): UnrepliedOverviewState {
    return restoreUnrepliedOverviewState(
        saved = saved,
        availableAccountIds = availableAccountIds,
        availableItemIds = availableItemIds
    ).copy(accountFilterId = null)
}
```

- [ ] **Step 4: 修改底部 Home 回调**
