# 悬浮聊天顶部栏状态驱动 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在悬浮聊天工作区顶部槽位实现 iOS 对齐的四态顶部栏，并保持聊天区和底部栏行为不变。

**Architecture:** 在 `FloatingChatOverlayUi.kt` 增加纯状态解析函数和顶部栏 Composable，使用 `FloatingChatRuntimeSections.topContent` 统一布局。`CoordinateChatBody` 仅提供隐藏旧工具栏和消息滚动回调两个集成点，所有消息/底部渲染逻辑保持原样。

**Tech Stack:** Kotlin、Jetpack Compose、Compose Material 3、JUnit。

---
