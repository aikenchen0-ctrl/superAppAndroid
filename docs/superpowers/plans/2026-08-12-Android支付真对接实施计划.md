# Android 支付真对接实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 Android 悬浮聊天红包、转账、零钱和领取流程接入 SCRM `/payments/*` 真实异步任务，并移除本地假成功。

**Architecture:** 保留 `ScrmApiClient` 作为唯一 HTTP 客户端，在 `PaymentFlow.kt` 增加请求校验、幂等键复用和任务终态编排。Compose 只负责收集输入与展示状态，发送卡片和已领取状态仅在任务终态成功后更新。

**Tech Stack:** Kotlin、kotlinx.serialization、Jetpack Compose、JUnit4、现有 SCRM Task API。
