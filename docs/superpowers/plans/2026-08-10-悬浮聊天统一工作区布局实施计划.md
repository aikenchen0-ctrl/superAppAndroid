# 悬浮聊天统一工作区布局实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**目标：** 将悬浮聊天的顶部、主体和底部输入区域纳入单一 Compose 垂直工作区。

**架构：** `FloatingChatRuntimeSections` 提供工作区容器和 overlay 层；`CoordinateChatBody` 内部使用 Toolbar + weighted body；普通 `BottomInputBar` 作为工作区底部 slot，底部抽屉继续作为面板 overlay。

**技术栈：** Kotlin、Jetpack Compose、JUnit contract tests、Gradle。
