# 群聊未回消息测试数据实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Debug APK 中为现有群聊注入覆盖未回判定边界的测试数据，并安装到 ADB 手机。

**Architecture:** 将群聊 fixture 作为 SCRM 包内的纯函数独立实现，由现有桥接层在 Debug 构建调用。私聊原有演示数据保持不变，群聊数据按场景生成并通过现有 `homeUnreadDemoMessages` 管线进入聚合页。

**Tech Stack:** Kotlin、Android Gradle Plugin、JUnit 4、ADB
