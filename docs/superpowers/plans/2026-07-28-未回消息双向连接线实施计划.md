# 未回消息双向连接线实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在未回消息聚合页同时绘制联系人头像到同一事项全部气泡的树形连接线，以及每条气泡到所属收件账号头像的连接线。

**Architecture:** 复用现有 `ConnectorCoordinateState`、`ChatConnectorLayer` 和 `createChatConnectorTree`。聚合消息由单一左侧目标扩展为“事项左侧目标 + 收件账号右侧目标”两个稳定键，绘图层按目标键自动聚合气泡形成左右连接树。

**Tech Stack:** Kotlin、Jetpack Compose Canvas、JUnit 4、Gradle Android Plugin、ADB

```kotlin
internal fun FloatingChatMessage.toHomeOverviewConnectorTargetKeys(
    connectorGroupId: String?,
    accountId: String?
): List<ConnectorTargetKey> {
    if (connectionTarget != FloatingChatConnectionTarget.User) return emptyList()
    val sessionKey = toHomeOverviewConnectorTargetKey(connectorGroupId) ?: return emptyList()
    val accountKey = accountId?.let { id ->
        ConnectorTargetKey(
            target = FloatingChatConnectionTarget.Account,
            targetId = id,
            lane = ConnectorAvatarLane.Account
        )
    }
    return listOfNotNull(sessionKey, accountKey)
}
```

- [ ] **Step 3: 实现可测试的稳定目标分组**

在 `ChatConnectorLayer.kt` 中新增：

```kotlin
internal fun homeOverviewConnectorTargetsByMessageId(
    messageIds: List<String>,
    connectorGroupIds: Map<String, String>,
    accountIds: Map<String, String>
): Map<ConnectorTargetKey, List<String>> {
    val grouped = linkedMapOf<ConnectorTargetKey, MutableList<String>>()
    messageIds.forEach { messageId ->
        val sessionId = connectorGroupIds[messageId] ?: return@forEach
        val sessionKey = ConnectorTargetKey(
            target = FloatingChatConnectionTarget.User,
            targetId = sessionId,
            lane = ConnectorAvatarLane.Session
        )
        grouped.getOrPut(sessionKey) { mutableListOf() }.add(messageId)
        accountIds[messageId]?.let { accountId ->
            val accountKey = ConnectorTargetKey(
                target = FloatingChatConnectionTarget.Account,
                targetId = accountId,
                lane = ConnectorAvatarLane.Account
            )
            grouped.getOrPut(accountKey) { mutableListOf() }.add(messageId)
        }
    }
    return grouped
}
```
