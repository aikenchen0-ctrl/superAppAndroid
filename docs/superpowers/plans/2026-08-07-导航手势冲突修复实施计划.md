# 导航手势冲突修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 Android 侧边系统手势与全屏无障碍悬浮窗边缘手势的冲突，并在 ROOT 设备上安全补足官方排除区的 200dp 限制。

**Architecture:** 保留现有小尺寸 `EdgeOverlayView` 的排除区行为，为原生触摸和展开浮聊的全屏路径新增非触摸 `TYPE_ACCESSIBILITY_OVERLAY` 排除区窗口。将现有安全设置接管器改为可注入 ROOT Shell、按侧决策并可恢复的控制器；无 ROOT 时不改变系统设置。

**Tech Stack:** Kotlin、Android AccessibilityService、WindowManager、`View.setSystemGestureExclusionRects()`、JUnit 4、Gradle。
