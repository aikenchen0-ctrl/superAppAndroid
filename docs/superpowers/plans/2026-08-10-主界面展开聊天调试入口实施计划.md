# 主界面展开聊天调试入口 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Debug 主界面提供一个调用真实悬浮聊天展开逻辑的顶置调试按钮。

**Architecture:** `UbikiAccessibilityService` 对现有 `FloatingChatOverlayController.expand()` 提供最小公开转发。`MainActivity` 只读取服务可用性并触发该转发，Compose 顶栏按 `BuildConfig.DEBUG` 决定是否渲染入口。

**Tech Stack:** Kotlin、Android AccessibilityService、Jetpack Compose、JUnit、Gradle。

---

### Task 1: 服务展开请求

**Files:**
- Modify: `ubiki-accessibility/src/main/kotlin/com/paifa/ubikitouch/accessibility/UbikiAccessibilityService.kt`
- Test: `ubiki-accessibility/src/test/kotlin/com/paifa/ubikitouch/accessibility/UbikiAccessibilityServiceTest.kt`

- [ ] **Step 1: 写失败测试**

为未初始化控制器时的返回结果和初始化后调用 `expand()` 的行为建立测试，测试名分别为 `requestDebugFloatingChatExpandReturnsFalseBeforeOverlayInitialization` 和 `requestDebugFloatingChatExpandExpandsInitializedOverlay`。

- [ ] **Step 2: 运行测试确认失败**

运行：`./gradlew.bat :ubiki-accessibility:test --tests '*UbikiAccessibilityServiceTest' --no-daemon`

预期：因 `requestFloatingChatExpandForDebug` 尚不存在而失败。

- [ ] **Step 3: 实现最小服务转发**

在 `UbikiAccessibilityService` 新增：

```kotlin
fun requestFloatingChatExpandForDebug(): Boolean {
    if (!::floatingChatOverlayController.isInitialized) return false
    floatingChatOverlayController.expand()
    return true
}
```

- [ ] **Step 4: 运行测试确认通过**

运行：`./gradlew.bat :ubiki-accessibility:test --tests '*UbikiAccessibilityServiceTest' --no-daemon`

预期：PASS。
