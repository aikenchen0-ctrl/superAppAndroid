# 返回手势扇形双框 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task with verification checkpoints.

**Goal:** 在三条现有返回手势输入路径上增加一致的扇形“功能一/功能二”视觉命中状态，同时保持未命中时原有返回动作不变。

**Architecture:** 在 `ubiki-core` 放置无 Android 依赖的选项模型、布局和命中器；输入层将命中结果写入 `BackGestureProgress`，由普通边缘 Overlay、原生 TouchInteraction 和悬浮聊天 Compose 手势共同传递。`BackWaveOverlayController` 复用同一几何布局绘制两个不可触摸的 Canvas 功能框，服务提交层只在命中且视觉层可用时消费手势。

**Tech Stack:** Kotlin/JVM、Android View/Canvas、Compose pointer input、JUnit 4、现有 Gradle 多模块工程。
