# 侧边功能完善实施计划

> 执行时逐项使用测试先行：先写失败测试，确认失败后再写最小生产代码。

**目标：** 使边缘手势动态显示、命中并执行配置的功能；提供独立配置页、应用分类、排序删除，并增强提示和上下滑反馈。

**架构：** `ubiki-core` 只管理配置限制和动态命中几何；`app` 只管理 Compose 设置 UI；`ubiki-accessibility` 读取配置、绘制文案并调用已有动作执行器；`ubiki-overlay` 只修改指示器和手势识别参数。
